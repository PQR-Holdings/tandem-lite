# Tandem Lite Support

For help with Tandem Lite, email [partners@pqr.llc](mailto:partners@pqr.llc) or open a GitHub issue.

Do not include API keys, credentials, private source code, screenshots containing sensitive information, or other confidential data in public issues.

Tandem Lite is currently beta software. When reporting a problem, include the extension version, operating system, VS Code version, selected provider, relevant non-sensitive output, and reproduction steps. Provider account, quota, and billing issues should be directed to the selected provider.
